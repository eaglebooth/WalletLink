GOOD TO KNOW

Before you approve

What does a wallet link do?

A link creates a public record that both wallets approved this address pair. Anyone can look it up to connect your profile across EVM and Solana.

Does linking give access to my tokens?

The WalletLink contract records and removes address pairs. Linking does not request token approvals. Transactions still require network fees.

Why do both wallets need to approve?

MetaMask proposes the pair and Phantom accepts it. The contract completes the link only when the specified Solana wallet approves the request.

Can I change my linked wallet?

Yes. Revoke your current link with either wallet, then create a new request. Each address can have one active link.
